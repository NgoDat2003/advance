B1 KEYS/lệnh chậm chặn mọi client vì một luồng chạy lệnh (lỗi 1) → runs 01-block.sleep.timeline, 01-why-fast.slowlog
B2 SET không TTL: key sống mãi, tới maxmemory với noeviction thì ghi bị từ chối OOM (lỗi 2) → runs 03-eviction.noeviction, 03-expiry.expire-dict
B3 DEL trơn xóa nhầm khóa của người khác khi khóa đã hết hạn; compare-and-delete thì không (lỗi 3) → runs 08-lock.ttldel.timeline, 08-lock-lua.cad.timeline
B4 GET rồi SET làm mất lượt đếm, INCR thì không (lỗi 4) → runs 05-counter.getset.timeline, 05-counter.incr.timeline
B5 Hash lớn tốn bộ nhớ và thao tác toàn bộ (HGETALL/DEL) chặn luồng chính; HGET một trường là O(1) (lỗi 5) → runs 06-practices.bigkey, 02-encodings.hash
B6 N lệnh tuần tự trả N round trip; MGET/pipeline gộp lại (lỗi 6) → runs 01-bench.mget, 01-bench.pipeline
B7 SET NX PX: chỉ một người lấy được khóa (chỗ đúng) → run 08-lock.nx.timeline
