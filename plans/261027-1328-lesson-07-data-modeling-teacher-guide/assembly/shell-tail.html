Quy tắc thiết kế

  1. Bắt đầu ở 3NF. Phi chuẩn hóa chỉ khi đo được lợi ích đọc, và luôn có câu đối soát (chặng 2, 9).
  2. Giữ khóa ngoại và đánh index cho cột FK. Kiểm tra trong app không thay được FK (chặng 3).
  3. Cột tham chiếu đặt ở entity sinh sau (slide 12).
  4. Migration: SET lock_timeout, ADD COLUMN với default hằng, index bằng CONCURRENTLY trong tab auto-commit (chặng 4).
  5. Table template: id, status có CHECK, data jsonb, version, created/updated at/by (slide 20).
  6. Sổ cái kép: bút toán là sự thật, số dư là cache; mỗi giao dịch tổng bằng 0; khóa ví theo id; idempotency key UNIQUE (chặng 9).

Ba câu đối soát sổ cái

SELECT transfer_id FROM ledger_entries GROUP BY transfer_id HAVING sum(amount) <> 0;   -- phải 0 dòng
SELECT sum(amount) FROM ledger_entries;                                                -- phải = 0
SELECT w.id FROM wallets w
WHERE w.balance <> (SELECT coalesce(sum(amount), 0) FROM ledger_entries e WHERE e.wallet_id = w.id);  -- phải 0 dòng
