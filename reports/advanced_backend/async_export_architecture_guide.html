Quy Trình 3 Giai Đoạn Chuẩn Enterprise

01

Giai đoạn 1: Khởi Tạo Tác Vụ Ngầm (Trả về sau 5 mili-giây)

Client: Gửi POST /api/v1/export-jobs (kèm bộ lọc: year=2025, brand=MAYCHA).

API Gateway: Đẩy tác vụ vào Queue nền (BullMQ Redis) ➔ KHÔNG ĐỢI XUẤT XONG!

Response ngay lập tức: Mã 202 Accepted kèm JSON: { "job_id": "job_exp_888", "status": "PENDING" }.

👉 Trình duyệt người dùng KHÔNG BỊ ĐƠ! Kế toán vẫn bấm xem hợp đồng, làm việc khác bình thường.

02

Giai đoạn 2: Polling Kiểm Tra Tiến Độ (Định kỳ 3s - 5s)

Worker: Chạy ngầm trong tiến trình riêng biệt. Đọc dữ liệu từ PostgreSQL theo từng cụm (Stream Cursor 1.000 dòng/lần), ghi dần vào file tạm trên đĩa cứng (không nạp 500MB vào RAM).

Client: Định kỳ 3 giây gọi: GET /api/v1/export-jobs/job_exp_888.

API Gateway: Trả về tiến độ hiện tại: { "status": "PROCESSING", "progress": 45 }.

👉 Giao diện người dùng hiện thanh progress bar nhảy mượt mà: 20% ... 45% ... 80%.

03

Giai đoạn 3: Hoàn Thành & Tải File Stream

Worker: Ghi file xong, đẩy file lên Storage (S3 / MinIO / Local Storage), cập nhật trạng thái job thành COMPLETED.

Client: Polling lần cuối nhận: { "status": "COMPLETED", "download_url": "/api/v1/downloads/job_exp_888.xlsx" }.

Tải file: Giao diện hiện nút xanh: [ Tải File Báo Cáo Về Máy ]. Kế toán bấm tải, backend stream file nhả về máy khách.

👉 Dù kế toán có tắt máy đi ăn trưa, chiều mở lên link tải vẫn còn đó (sẵn sàng trong 24 giờ).

So Sánh Trực Diện: Cách Đồng Bộ Cũ vs Cách Bất Đồng Bộ Chuẩn

Vấn đề kỹ thuật Cách Cũ: Gọi Đồng Bộ (`GET /export`) Cách Chuẩn: Async Polling (`202 Accepted`)
1. Giới hạn Timeout CHẾT VÌ 504 TIMEOUT: NGINX/Cloudflare tự động ngắt kết nối sau 60 giây. File 500MB chạy 2 phút là gãy! 0% TIMEOUT: Request khởi tạo trả về sau 5 mili-giây với mã 202 Accepted.
2. Tràn bộ nhớ (OOM Crash) SẬP SERVER: Nạp 500MB Excel thô vào RAM ngốn 2GB. 3 người cùng bấm xuất ➔ Server Node.js bị đứt bóng (Out of Memory). TIẾT KIỆM RAM: Worker dùng NodeJS Stream ghi thẳng ra đĩa, RAM chỉ tốn ~50MB bất kể file nặng bao nhiêu GB.
3. Nghẽn CPU Event Loop ĐỨNG SERVER: Tiến trình chính bận parse 200.000 dòng ➔ Toàn bộ user khác không thể đăng nhập hay đặt món! TÁCH BIỆT TIẾN TRÌNH: Worker chạy ở Background thread/container riêng, không ảnh hưởng 1 mili-giây nào đến web chính.
4. Trải nghiệm người dùng ỨC CHẾ: Trình duyệt đơ, chuột quay mòng mòng, user tưởng lỗi bấm liên tục 5 lần khiến server quá tải. CHUYÊN NGHIỆP: Thanh tiến độ nhảy %, user vẫn lướt web làm việc khác, thông báo chuông khi file xong.

Code Mẫu Triển Khai NestJS + BullMQ Queue

1. Controller: Nhận request và trả ngay 202 Accepted

@Controller('export-jobs')
export class ExportController {
  constructor(
    @InjectQueue('export-queue') private readonly exportQueue: Queue,
  ) {}

  @Post()
  @HttpCode(HttpStatus.ACCEPTED) // Trả về 202 Accepted chuẩn RESTful!
  async triggerExport(@Body() dto: ExportRequestDto) {
    const job = await this.exportQueue.add('generate-excel', dto, {
      removeOnComplete: false, // Giữ lại metadata để client polling
      removeOnFail: false,
    });

    return {
      job_id: job.id,
      status: 'PENDING',
      status_check_url: `/api/v1/export-jobs/${job.id}`,
    };
  }

  @Get(':id')
  async getStatus(@Param('id') id: string) {
    const job = await this.exportQueue.getJob(id);
    if (!job) throw new NotFoundException('Không tìm thấy Job!');

    const state = await job.getState(); // pending, active, completed, failed
    const progress = job.progress;

    return {
      job_id: job.id,
      status: state.toUpperCase(),
      progress: progress || 0,
      download_url: state === 'completed' ? `/api/v1/downloads/${job.id}.xlsx` : null,
    };
  }
}

2. Consumer Worker: Chạy ngầm và Stream file

@Processor('export-queue')
export class ExportProcessor {
  @Process('generate-excel')
  async handleExport(job: Job) {
    // 1. Dùng Cursor đọc PostgreSQL từng cụm (không load toàn bộ vào RAM):
    const total = 200000;
    let processed = 0;

    // 2. Dùng thư viện exceljs dạng STREAM:
    const workbook = new ExcelJS.stream.xlsx.WorkbookWriter({
      filename: `./storage/exports/${job.id}.xlsx`,
    });
    const sheet = workbook.addWorksheet('BaoCao');

    for await (const batch of this.fetchBatchesFromDb()) {
      for (const row of batch) {
        sheet.addRow(row).commit();
        processed++;
      }
      // Cập nhật tiến độ cho Client polling
      await job.progress(Math.round((processed / total) * 100));
    }

    await workbook.commit();
    return { success: true };
  }
}
