Quy tắc dùng Redis

  1. Không chạy lệnh O(N) trên keyspace hay key lớn ở đường request: SCAN thay KEYS, UNLINK thay DEL cho key lớn (chặng 1, 6).
  2. Gom lượt mạng: MGET/pipeline thay cho N lệnh nối tiếp (chặng 1).
  3. Đọc-sửa-ghi phải nguyên tử: lệnh có sẵn (INCR, HINCRBY) hoặc Lua (chặng 2, 5, 6, 9).
  4. Mọi khóa cache có TTL kèm jitter; chọn maxmemory-policy theo vai trò của instance (chặng 3, Bài 02).
  5. Biết mình mất gì khi sập: RDB mất từ ảnh chụp cuối, AOF everysec chỉ mất khi hệ điều hành sập (chặng 4).
  6. Khóa phân tán: SET NX PX + token, nhả bằng compare-and-delete, fencing token cấp cùng script với lệnh lấy khóa và được kiểm ở chỗ ghi cuối (chặng 8).
  7. Replica có thể trả dữ liệu cũ; trong Cluster, khóa dùng chung lệnh phải chung hashtag (chặng 7).
