Lab 3.06 — Covering index: Index Only Scan chỉ "không đụng heap" khi visibility map cho phép (slide 28, 38)

A. SELECT name, email … WHERE country = 'SG' AND province = 'SG-P3' trên users (1 triệu dòng)
─────────────────────────────────────────────────────────────────────────────────────────────
│ Truy vấn                                            │ Kế hoạch                      │ Dòng │          Heap Fetches │ Trang │    ms │
├─────────────────────────────────────────────────────┼───────────────────────────────┼──────┼───────────────────────┼───────┼───────┤
│ (country, province) — 6.8 MB                        │ Index Scan (l06_cp_nodedup)   │  496 │ — (đọc heap mọi dòng) │   487 │ 0.530 │
│ (country, province) INCLUDE (name, email) — 65.1 MB │ Index Only Scan (l06_cp_incl) │  496 │                     0 │     8 │ 0.263 │
   => ✔ INCLUDE → Index Only Scan, Heap Fetches 0: 8 trang thay vì 487 (61× ít hơn)
   => ✔ Cái giá: index INCLUDE nặng 65.1 MB, gấp 9.6× bản chỉ có khóa (6.8 MB). Một phần vì INCLUDE không được khử trùng lặp (bản khóa tắt dedup: 29.6 MB), phần còn lại (2.2×) là name, email chép vào mọi mục. Slide 28: giữ ≤ 5 cột
